# 阚教授的动态空间实验室 (Professor Kan's Dynamic Space Lab)

这是一个基于 **Streamlit** 构建的跨洋实时协同工程教学平台。该项目专门为退休机械工程专家——**阚教授（婆婆）**定向开发，方便她远程指导身在美国的外孙学习《机械识图》及工程几何等专业知识。

项目集成了音视频通话、Web-AR 3D模型投影、实时协同工程绘图白板以及定制化的 AI 学术助理，打造了一个沉浸式的远程“祖孙联合工程绘图室”。

##  核心功能特性

### 1. 实验室控制台 & 视频传输协议
* **多模式切换：** * **普通通话模式 (Jitsi)：** 基于开放的 Jitsi Meet，连接迅速，适合多方学术讨论。
  * **高清制图模式 (VDO.ninja)：** 提供 4K 级别超低延迟、高清晰度画面，方便精确观察微小机械零件的尺寸与细节。
* **统一房间机制：** 自动生成随机且唯一的 `Room ID`（如 `Lab_Session_a1B2c3D4e5`），确保视频、白板等所有协同组件在同一频道内无缝同步。

### 2. 空间投影站 (Web-AR 3D 交互)
* **跨平台模型支持：** 完美兼容安卓/网页端 (`.glb`) 及苹果 iOS AR 专用 (`.usdz`) 格式的模型上传。
* **桌面增强现实投影：** 采用 `<model-viewer>` 组件。外孙上传 CAD 导出的模型后，阚教授可在 iPad/手机端点击 **“✨ 将此零件投影到我的桌面”**，通过摄像头将 3D 零件直接 1:1 投射到真实的办公桌上进行旋转和缩放讲解。

### 3. 祖孙联合工程绘图室 (实时协同)
* **Excalidraw 协同白板：** 深度集成 Excalidraw，双方共用同一 Room ID。孙子在电脑前画图，外婆在另一端刷新即可实时看到、修改并批注。

### 4. 文献与课题检索终端 (安全拦截 AI 助理)
* **角色注入：** 基于 OpenAI `gpt-4o` 模型定制的专属学术助理，以极其恭敬、专业的语气称呼阚教授为“婆婆”。
* **【最高安全指令】反诈与关怀拦截：** 若检测到婆婆在网上检索不实保健品、理财投资、偏执八卦等高风险内容，AI 助手将执行**礼貌拦截**——不直接拒绝，而是巧妙地将话题引回机械工程领域（例如提示外孙正被“等轴测图尺寸标注”难题困扰），从而对老年人进行贴心的网络安全保护。
* **完善的错误自愈：** 内置网络错误分析链（`_network_error_hint`），针对常见的国内代理、DNS 解析失败、SSL 证书及超时错误提供大白话式的排查指引。
